# Precision Patch — Launch Checklist

## Gate A — Business
- [ ] Final consumer brand selected and cleared.
- [ ] Legal entity confirmed.
- [ ] Business address confirmed.
- [ ] Support/privacy email and phone active.
- [ ] Product liability coverage reviewed.
- [ ] Supplier/exclusivity rights documented.

## Gate B — Product
- [ ] Final product photos received.
- [ ] Front/back label received.
- [ ] Exact finished-product formula received.
- [ ] Manufacturer/distributor documented.
- [ ] Lot/batch process documented.
- [ ] Finished-product testing received and matched to actual lot/product.
- [ ] Directions/warnings/storage/expiration received.
- [ ] Final product classification/legal pathway reviewed.
- [ ] Website copy checked against the final label and supporting documentation.

## Gate C — Website
- [x] Bright consumer storefront architecture.
- [x] Account flow prototype.
- [x] Product acknowledgement/intake prototype.
- [x] Product page shell.
- [x] Order review/checkout shell.
- [x] Privacy Policy.
- [x] Terms & Conditions.
- [x] Shipping Policy.
- [x] Returns & Refunds Policy.
- [x] Product Use & Safety page.
- [x] Cookie/tracking notice.
- [x] Subscription policy framework.
- [x] Standing compliance guardrails.
- [ ] Real domain.
- [ ] Production authentication/database.
- [ ] Final product content inserted.
- [ ] Real price/SKU/package count inserted.
- [ ] Real contact/legal information inserted.
- [ ] Accessibility/mobile QA.
- [ ] Production analytics/privacy choices configured only after vendor selection.

## Gate D — Merchant processing
- [x] Underwriting packet skeleton prepared.
- [ ] Select processor/acquirer.
- [ ] Submit complete truthful underwriting packet.
- [ ] Processor confirms actual business/product acceptance.
- [ ] Production merchant account approved.
- [ ] Payment integration completed.
- [ ] Test authorization/capture/refund/void flows.
- [ ] Chargeback contact and descriptor confirmed.
- [ ] Payment remains OFF until all preceding items pass.

## Gate E — Fulfillment
- [ ] Inventory location decided.
- [ ] Supplier drop-ship vs owned fulfillment decided.
- [ ] Carrier(s) selected.
- [ ] Packaging/shipper materials confirmed.
- [ ] Return address confirmed.
- [ ] Processing-time SLA confirmed.
- [ ] Tracking notification flow configured.
- [ ] Lost/damaged/mis-shipped process tested.
- [ ] Lot recorded against each shipped order where applicable.

## Gate F — Customer operations
- [x] Customer-service SOP drafted.
- [x] Order-status model drafted.
- [ ] Support inbox/helpdesk selected.
- [ ] Refund/replacement authority limits assigned.
- [ ] Escalation contact assigned.
- [ ] Product complaint/adverse-event process finalized from actual product requirements.
- [ ] Canned responses reviewed against compliance guardrails.

## Gate G — Launch marketing
Only after product/processor approval:
- [ ] Real product photography.
- [ ] Final package assets.
- [ ] Email welcome flow.
- [ ] Order/ship/delivery emails.
- [ ] Abandoned-cart flow after processor approval.
- [ ] Subscription lifecycle messages if used.
- [ ] Paid-ad account/pixel setup only after privacy review.
- [ ] Social/affiliate scripts reviewed under `COMPLIANCE-GUARDRAILS.md`.

## Hard stop
Do **not** enable public payment merely because the site is finished. Production launch requires actual product documentation, accurate labeling, fulfillment readiness, and processor/acquirer approval of the real product/business model.
